# Трекінг задач

- **Основний трекер:** [GitHub Issues](https://github.com/yerzan/ambulance-project/issues) з milestones Phase 0–7 (GDD §17) і labels `type:*`, `area:*`, `priority:*`, `mvp`.
- **Дошка:** GitHub Project «LAST CALL» (Board), колонки: Backlog → Ready → In Progress → Review → Done.
- **Дзеркало:** [`BACKLOG.md`](BACKLOG.md) — оновлюється разом із PR.
- **Нова задача:** шаблон `.github/ISSUE_TEMPLATE/task.md`, назва `LC-xxx: …`.
- **Гілка:** `feature/LC-006-stretcher-prototype` → PR у `develop` (шаблон PR містить DoD).
